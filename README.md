# 🛡 Proofs

**Proofs** — Paper-плагин античит-проверок (proofcheck) для **Minecraft 1.21.x** (Paper, Java 21+ / 25).

Позволяет администрации вызывать игроков на проверку «вживую»: с меню голов онлайн-игроков,
напоминаниями на экране и в чате, полным блокированием действий проверяемого и наказанием за выход из игры.

---

## ✨ Возможности

| Функция | Описание |
|---|---|
| `/proofs` | Открывает GUI-меню с головами всех игроков онлайн |
| Клик по голове | Открывает меню игрока с кнопками **«Вызвать на проверку»**, **«Спек»** и **«Назад»** |
| `/proofs <ник>` | Вызывает игрока на проверку напрямую (как кнопка «Вызвать») |
| Красный текст | Каждые 10 секунд проверяемый видит на экране красный текст **«Проверка на читы»** (title + action bar) |
| Напоминание в чате | Каждые 10 секунд проверяемому приходит сообщение **«Напишите ваш discord или anydesk»** |
| Блокировка действий | Во время проверки нельзя: менять слоты hotbar и предметы в инвентаре, открывать чужие инвентари, ломать/ставить блоки, использовать предметы, дропать/подбирать предметы, менять gamemode, использовать команды |
| Неуязвимость | Проверяемый получает `invulnerable` на время проверки (подсветка/glowing **не** включается) |
| Сброс после проверки | По завершении все ограничения, эффекты и напоминания снимаются, состояние игрока восстанавливается |
| 💀 Наказание за лог-аут | Если игрок выходит во время проверки — он **умирает и теряет все ресурсы** (инвентарь выбивается на землю) |
| 👁 Спек | Кнопка **«Спек»** телепортирует админа, открывшего меню, к выбранному игроку в режиме наблюдателя (`SPECTATOR`) |
| `/proofs end <ник>` | Завершает проверку конкретного игрока |
| `/proofs stop` | Завершает все активные проверки |

## 🔨 Сборка

```bash
mvn clean package
```

Готовый JAR появится в `target/Proofs-1.1.0.jar`. Положите его в папку `plugins/` вашего Paper-сервера.

> Требуется **Java 21+** (совместимо с Java 25) и **Paper 1.21.x**.

## ⚙️ Конфигурация (`config.yml`)

```yaml
check:
  reminder-interval-seconds: 10   # интервал напоминаний проверяемому (сек)
```

## 🔑 Права (permissions)

| Permission | По умолчанию | Описание |
|---|---|---|
| `proofs.use` | OP | Доступ к команде `/proofs` и меню |
| `proofs.admin` | OP | Уведомления о начале/окончании проверок и о лог-аутах во время проверки |
| `proofs.check.end` | OP | Завершать активные проверки (`/proofs end`) |
| `proofs.spectate` | все | Кнопка «Спек» в меню |
| `proofs.*` | OP | Все права плагина (children) |

## 📸 Как это работает (UX-поток)

1. Админ вводит `/proofs` → видит меню с головами игроков онлайн.
2. Кликает по голове нужного игрока → меню действий.
3. Нажимает **«Вызвать»** (или использует `/proofs <ник>`) → у игрока начинается проверка:
   - каждые 10 сек: красный текст на экране + сообщение в чат про discord/anydesk;
   - любые действия заблокированы, игрок неуязвим.
4. При необходимости жмёт **«Спек»** → телепорт к игроку в режиме наблюдателя.
5. По окончании админ использует `/proofs end <ник>` (или `/proofs stop`).
6. Если игрок вышел во время проверки → смерть + потеря всего инвентаря, админы получают уведомление.
